## 四个必填参数怎么填

最低价、最高价、网格数量、投资金额，这四个不填完机器人建不起来。

### 最低价和最高价：这是机器人的工作边界，不是止损

官方定义很干脆：市场价跌破最低价，机器人停止挂单；市场价超出最高价，机器人也停止挂单。

注意“停止挂单”这四个字。价格越界之后机器人不干活了，但你手里的币还在账户里，没有自动卖出。要不要在某个价位清仓，是另一个开关管的事——止损 SL。很多人把区间下沿当成止损位来设，结果价格跌穿以后机器人停工、持仓继续浮亏，这跟设了止损是两回事。

设这两个数的时候问自己一句：未来几周价格大概率在这个范围里来回吗？区间太窄，价格一出去机器人就闲置；区间太宽，资金被摊薄，每一格能赚的价差变小。

### 网格数量：官方原话是“越多单笔越小，频率越高”

欧易文档里的原话是：“网格数量越多，机器人执行的交易规模越小，但频率更高；网格数量越少，交易规模越大，但频率更低。”

这是取舍，不是越多越好。格数多，每格价差小，成交次数多，手续费也反复发生；格数少，单笔大，成交稀疏。

官方还给了一个算例：价格范围 100 到 400，网格数量设 3、选算术模式，会切出 100–200、200–300、300–400 三层。三格意味着什么？价格从 100 涨到 400，中间只有两次卖出机会。想让机器人多跑几趟，格数就得往上加。

### 投资金额

文档里的说法是“通常不能超过交易账户中的可用余额”。这句没有例外条款，实际操作就是先看账户里有多少可用资金，再决定投多少。别把生活要用的钱和这个账户混在一起，原因在下面“安全”那节会讲。

### 算术模式和几何模式怎么选

算术模式下每层之间的差值固定，官方举例 1、2、3、4。几何模式下每层之间的比例固定，举例 1、2、4、8。

差价固定的意思是每格赚的绝对金额差不多；比例固定的意思是每格赚的百分比差不多。价格绝对值大、波动以点数计的标的，算术更直观；价格低、波动以百分比计的标的，几何更贴合它的走势。这条没有官方推荐，属于我根据两种模式的定义给的判断。

## 三个可选参数，以及按下“停止”之后会发生什么

可选参数有三个：

- **上移/下移**：让机器人跟着市场价格波动动态调整网格，官方说法是“提高资金利用率”。
- **止盈（TP）**：市场价到这个水平，机器人停止交易并卖出所有持有资产。
- **止损（SL）**：市场价跌到这个水平，机器人停止交易并卖出所有持有资产，用来控制亏损。

止盈止损和区间边界的区别在这里最清楚：TP/SL 会卖出全部持仓，最高价和最低价只让机器人停工。

机器人跑起来以后，看板上有五个动作：修改参数（运行中仍可调整价格区间和网格数量）、提取收益、停止机器人、查看详情、复制配置。详情页看两个数——已完成订单的成交总量，和“匹配交易”的笔数，后者统计的是低买高卖完成的回合数。

按下“停止”之后会发生什么，是很多人不敢点的那一下。官方写得很清楚：所有挂单会被取消，你可以选择按市价卖出持有资产，或者保留资产，资金或数字资产会自动转回交易账户。也就是说，停止这个动作不会把你的币锁在机器人里，也不会强制平仓，卖不卖由你当场决定。

## 官方自己列的四种会亏钱的情况

这一段是原文，欧易在帮助文档里主动写了网格的局限：

- 在强趋势行情中，部分买卖单可能无法成交；
- 在下跌趋势中，已成交的买单可能导致亏损；
- 市场突变时，网格交易可能缺乏灵活性；
- 由于交易频率较高，可能会导致较高的交易成本，特别是在行情剧烈波动时。

翻成你能对上号的场景：

**单边上涨。** 价格一路向上，你的卖单在途中被逐格吃掉，底仓越卖越少，最后手里剩的币不多，涨幅跑不过一直拿着不动的人。网格赚的是震荡里的差价，趋势里它先天吃亏。

**单边下跌。** 每跌一格成交一次买单，账面浮亏一层层加上去。只要价格还在区间内，机器人会继续买，直到跌破最低价停工——那时浮亏已经形成了。

**突然跳空。** 消息面一砸，价格直接跨过好几层网格，中间的挂单没成交，机器人的节奏被打乱，它不会因为“这次不一样”而改变行为，参数写的是什么就执行什么。

**手续费吃掉价差。** 格数设得密，成交次数多，每笔都要付手续费。价差薄到一定程度，看起来在低买高卖，实际是在给手续费打工。欧易文档没给具体费率数字，你也别信任何没标出处的费率表——按你账户实际显示的费率去算。

这四条不是免责套话，是产品说明。看到这儿还愿意用，说明你清楚它在什么行情里能派上用场。

## AI 交易机器人是不是另一回事

Agent Trade Kit 管的是入口：你用日常语言说出需求，它转成具体下单指令。策略还是账户里那套网格，只是参数不用你手算。

官方给的安装步骤是两步：先运行 `npx skills add okx/agent-skills` 装欧易 Skill，再运行 `npm i -g @okx_ai/okx-trade-cli` 装最新版并连接账户，然后完成欧易账户授权，就可以开始。

支持 OpenClaw、Claude、Claude Code、Codex、Cursor。官方 FAQ 里的口径更宽：所有兼容 MCP（Model Context Protocol）协议的客户端都能用，包括 Claude Desktop、Claude Code、Cursor 以及各类 MCP SDK 自定义的 Agent。目前在本地设备上运行，云端（Remote MCP）部署还没上线。

它带三个即插即用的 Skill，分工很明确：

- `okx-cex-market`：行情数据。最新行情、盘口深度、K 线、资金费率、持仓量、指数数据，不需要 API Key 就能调。
- `okx-cex-trade`：交易。现货、合约、期权、算法订单，支持 OCO、移动止盈止损和网格策略。
- `okx-cex-portfolio`：资产组合。余额、持仓、收益明细、账单历史、费率等级、资金划转。

网格能力写在 `okx-cex-trade` 里面。这就是手动和 AI 两条路的关系：Agent 没有另造一套网格引擎，它调的是同一个交易能力。两边参数是否逐项完全一致，官方文档没有对比说明，我不替它下结论。

官方示例指令可以直接感受一下粒度：

- “设置一个 ETH/USD 网格，价格区间 $3,200 到 $3,800，共 10 格”
- “查看我过去一周的盈亏和总手续费”
- “市价买入 500 USD 的 ETH。在 3,800 止盈，3,500 止损”
- “我有 1,000 USD，每次 BTC 下跌 2% 就买入”
- “撤销我所有 BTC/USD 的当前委托”

第二条和第五条是手动操作里最费时间的活：翻账单算手续费、对着列表一个个撤单。这两件事交给 Agent 确实省事。

还有一个常被误解的点：Agent 能不能帮你开合约，取决于你账户本身有没有这个权限。官方用了个比喻，“可以把它当成一个遥控器：它只能控制电视本身支持的功能，无法播放您没订阅的频道”。它绕不过规则，也改不了你的交易权限。

## 安全：官方四层机制的六条，和给你的七条

开发者在 FAQ 里说“内置了四层安全机制”，具体列出来是六条：

- 密钥只存本地，AI 全程碰不到；
- 只读模式，AI 只能看不能动；
- 模块权限控制，精确决定 AI 能用哪些功能；
- 实盘与模拟盘完全隔离；
- 限速保护，异常指令自动拦截；
- 完全开源，每一行代码都能自己审计。

密钥具体存在哪，官方也写了：本地配置文件 `~/.okx/config.toml`，签名过程完全在本地完成，除欧易官方服务器外没有数据发给第三方。另外还有两个运行模式：`--demo` 走模拟交易，`--read-only` 限制 AI 只能查询数据。

官方对用户提了七条要求，前四条是配置层面的：

1. 给 AI 单独开子账户，专 Key 专用，不混用；
2. AI 账户只放给 AI 专用的钱，和主账户分开；
3. 不要在对话里把 API Key 直接发给 AI；
4. 交易权限设成“需要许可”，每一笔你说了才算；
5. 第一次用先开模拟盘，跑通了再切实盘；
6. 切勿向 Agent 透露敏感信息；
7. 不要安装或启用非官方 Skills。

第 4 条和第 1 条是配套的：子账户隔离资金，权限设成需要许可，等于给每一笔自动下单加了一道人工确认。第 6 条容易被忽略——你跟 AI 聊策略时顺口说出的助记词、密码、验证码，跟 API Key 一样不能出现。

官方在风险披露里写得很直白：“AI 模型可能会犯错、产生幻觉或基于过时信息行动。”还写了这个工具包依赖第三方大语言模型，欧易无法控制、验证或背书这些模型，也不对输出结果负责。建议是最小权限原则——除非绝对必要，不要开提币权限；绑定受信任的 IP；实盘放大资金前先小额测试。最后一句是“不构成任何财务、投资、法律或税务建议”。

带着这些去看“AI 帮我炒币”这个说法，边界就清楚了：它是个执行工具，判断责任在你。

## 什么行情别开网格，谁不适合用

三类人先别急着建机器人：

**打算长期拿着不动的人。** 网格在上涨过程中会不断卖出持仓，你要的是囤币，它做的是高抛低吸，目标相反。

**判断接下来是单边行情的人。** 无论向上还是向下，官方列的前两条局限都会找上你，网格在趋势里的表现不如直接持有或直接离场。

**资金小到手续费占比明显偏高的人。** 格数密、成交频繁，手续费是反复发生的固定支出。没有具体费率数字我没法替你算盈亏平衡点，但你可以先在建机器人时看一眼页面显示的手续费预估，再决定格数。

反过来，价格在一个区间里来回磨、你又不想天天盯盘的时候，是网格的主场。策略交易这件事的价值在于省掉盯盘时间，官方文档的说法是“帮助您利用程序化交易智能完成下单，为您节省了盯盘时间”。省时间是真的，稳赚不是。

## 怎么选：三种人的三条路

**只想省掉盯盘。** 用网页端现货网格，四个参数按上面的方法填，止损单独设一个你真正愿意认亏的价位，别拿区间下沿代替。先跑一两周看匹配交易的笔数和手续费支出，再决定要不要加资金。

**手里订单多、还想随时查组合。** 装 Agent Trade Kit，先 `--demo` 跑模拟，再 `--read-only` 只读观察，确认指令理解没问题再开实盘权限。批量撤单、查一周盈亏和手续费这两件事，用它比手动点省时间。

**想先试水。** 模拟盘 + 小额实盘，两个一起用。官方的建议本来就是“第一次用可以先开模拟盘，跑通了再切实盘”。

下单前最后确认两件事：

一，最低价和最高价是你判断的震荡区间，不是你的止损位，止损要单独开 SL。

二，想清楚按下“停止”那一刻你选市价卖出还是保留资产。这个决定最好在开仓前就想好，别等浮亏了再临时拍。
